# مزرعة قرضة ورظف للفراولة

نظام عربي متجاوب لإدارة الإنتاج والمخزون والمبيعات والمصروفات وحسابات الشركاء في مزرعتي قرضة ورظف.

## طريقة العمل

- **الواجهة**: صفحات ثابتة على GitHub Pages (بدون خادم ولا تكلفة).
- **قاعدة البيانات**: Google Sheets عبر Google Apps Script.
- **الصور**: Google Drive (مجلد `almazraatain-photos`) — خاصة، لا تُفتح إلا من داخل التطبيق.

## الوظائف

- تسجيل جولة قطاف بصورة **مباشرة من الكاميرا داخل التطبيق** (لا يمكن الاختيار من ألبوم الصور).
- اختيار المزرعة الأقرب تلقائيًا من موقع الجهاز مع السماح بالتعديل يدويًا.
- رقم تشغيلة تلقائي بتوقيت الرياض، مثال: `QAR-20260808-001`.
- بيع نقدي أو آجل، مع حساب سعر السلة وصافي الحصيلة بالهللات كأعداد صحيحة (بلا كسور عشرية عائمة).
- منع البيع فوق المخزون المتاح على مستوى الخادم.
- تسجيل المصروفات بصورة الفاتورة، وتوزيعها على المزرعتين أو اعتبارها مشتركة.
- تحصيل المبالغ الآجلة (سداد كامل أو جزئي) وتنبيه المتأخرات.
- **سجل حركات** لكل عملية: التاريخ، الوقت، المستخدم، الصورة، والموقع الجغرافي مع التحقق من قربه للمزرعة.
- لوحة إدارة: إنتاج، مبيعات، مصروفات، حسابات الشركاء، وإدارة المستخدمين.
- إلغاء العمليات بقيد عكسي (لا حذف) مع سبب الإلغاء، ومنع إلغاء جولة قطاف بيعت سلالها.

## البيانات الأساسية

- قرضة: `18.307193, 42.429743` — رمز `QAR`
- رظف: `18.249335, 42.496246` — رمز `RAD`
- الشريكان: عبدالاله آل جابر ومعاذ آل جابر، بنسبة 50% لكل منهما.
- المنطقة الزمنية: `Asia/Riyadh` (UTC+3)، والعملة: الريال السعودي.

## التثبيت

### 1) الخادم (Google Apps Script)

1. أنشئ جدول بيانات جديد في [Google Sheets](https://sheets.new) وسمِّه `مزرعة قرضة ورظف`.
2. من القائمة: **الإضافات ← Apps Script**.
3. احذف الكود الموجود، وألصق كامل محتوى `apps-script.gs`.
4. **Ctrl+S** (أو ⌘+S) للحفظ.
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخ رابط `/exec` الناتج.

> عند تحديث الكود لاحقًا: استخدم **Manage deployments ← ✏️ ← New version** حتى لا يتغيّر رابط `/exec`.

### 2) الواجهة

ضع رابط `/exec` في أول `app.js`:

```js
var API_DEFAULT = 'https://script.google.com/macros/s/.../exec';
```

ثم ارفع الملفات إلى مستودع GitHub وفعّل GitHub Pages من الفرع `main`.

### 3) أول تشغيل

افتح الموقع — ستظهر شاشة **إنشاء حساب المدير**. أدخل رقم الجوال وكلمة مرور من 8 خانات فأكثر.
بعدها أضف الشريك من **لوحة الإدارة ← المستخدمون ← إضافة مستخدم جديد**.

## الأمان

- كلمات المرور مخزّنة كبصمة SHA-256 مع ملح عشوائي لكل مستخدم — لا تُحفظ كنص صريح.
- الجلسات برموز عشوائية صالحة 30 يومًا، مخزّنة في الجدول ويمكن إبطالها.
- كل قراءة أو كتابة تمرّ بالتحقق من الجلسة على الخادم.
- الصور خاصة في Drive، وتُقرأ فقط عبر الخادم بعد التحقق من الجلسة.
- الملفات لا تحتوي أي مفتاح خدمة مدفوعة أو سر خارجي.

## تصفير البيانات

احذف صفوف الجداول `Harvests` و`Sales` و`Expenses` و`Payments` من جدول Google Sheets مباشرة (أبقِ صف العناوين).
لإعادة الإعداد من الصفر احذف كذلك صفوف `Users` و`Sessions` — سيعود التطبيق لشاشة إنشاء حساب المدير.
